# qh for Mac (and later iPhone)

A SwiftUI app in the qh design: a sidebar of your projects, a tab per project, qh running in each tab
in a real terminal (SwiftTerm). It runs the qh you installed; later it attaches to `qh serve`.

On a Mac with Xcode:

    brew install xcodegen
    xcodegen && open qh.xcodeproj    # then ⌘R

⌘O opens a project folder, ⌘W closes the tab, ⌘1–9 switch tabs. Light and dark follow the Mac.
